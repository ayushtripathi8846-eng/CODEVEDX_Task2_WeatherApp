# Weather App

A sleek modern weather application built with Vite, Tailwind CSS, and the OpenWeather API.

![Demo Screenshot](weather_app_screenshot_1780051278800.png)

## Features
- Dark mode UI with glassmorphism effects
- Real‑time weather data for any city
- Responsive design for mobile and desktop

## Setup
```bash
# Clone the repo (already done)
# Install dependencies
npm install
# Create a .env file (see .env.example) with your OpenWeather API key
# Start the dev server
npm run dev
```

## Build
```bash
npm run build
```
